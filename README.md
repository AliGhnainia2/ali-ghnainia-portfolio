# Ali Ghnainia | Developer Portfolio

A bilingual portfolio showcasing my Java / Spring Boot full-stack work, production systems, and selected projects.

## Tech stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- App Router

## Key features

- English and French versions
- Responsive desktop and mobile layouts
- Dedicated project case studies
- Original architecture visuals
- Downloadable English and French CVs

## Featured projects

- **SAEIV** — Real-time transport supervision built with Spring Boot microservices, Kafka, and Angular.
- **STATLINK** — Analytics and reporting platform with Spring Boot, React, Cube.js, and PostgreSQL.
- **Technical Chat** — Real-time messaging application with Spring Boot, WebSocket/STOMP, MongoDB, and Angular.

## Run locally

Requires Node.js 20.9+ and npm.

```bash
npm install
npm run dev
```

Open [English](http://localhost:3000/en) or [French](http://localhost:3000/fr).
